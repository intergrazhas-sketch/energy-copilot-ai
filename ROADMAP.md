# Energy Copilot Roadmap

## Product Vision

Enterprise SaaS platform for energy asset management and forecast intelligence.

## Phase 1

Infrastructure, backend foundation, forecast data model, telemetry ingestion, accuracy lab, dashboard MVP.

## Phase 2

Telemetry dashboard, rejected telemetry UI, provider comparison by plant, real forecast provider integration, audit log, production hardening.

## Phase 3

BESS optimization, predictive maintenance, AI engineer/RAG, executive AI, digital twin, mobile field app.

## Commercial Goal

Show measurable reduction of forecast error and financial value from imbalance reduction.

## UI Principle

Simple trilingual interface for non-technical operators, engineers, managers, executives.

## Technical Principle

Clean architecture, DDD-friendly modular monolith first, no permanent technical debt.

## Deployment Principle

Local verification before GitHub push and before Serverscore/production.
